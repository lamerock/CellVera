# Code of Conduct

CellVera aims to maintain a respectful, constructive, and welcoming project community.

## Expected behavior

Participants are expected to:

- Be respectful when discussing ideas, bugs, and implementation choices.
- Give technical feedback about the work rather than attacking the person.
- Assume good intent while still communicating clearly about problems.
- Respect privacy and avoid sharing another person's private information.
- Help keep issues and pull requests focused and useful.

## Unacceptable behavior

Harassment, threats, discriminatory abuse, sustained personal attacks, doxxing, spam, and intentionally disruptive behavior are not acceptable in project spaces.

## Enforcement

Project maintainers may edit or remove comments, close discussions, reject contributions, or restrict participation when behavior materially harms the project or its participants.

If you need to report conduct that should not be discussed publicly, contact the project maintainer through an appropriate private GitHub channel rather than opening a public issue.

This code of conduct applies to project-controlled spaces, including issues, pull requests, discussions, and release-related collaboration.
